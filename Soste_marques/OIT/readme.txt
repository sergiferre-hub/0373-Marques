# Pàgina Web OIT - Practica

Pàgina web informativa sobre l'Organització Internacional del Treball (OIT) feta per a l'assignatura de Sostenibilitat.

---

##Estructura del projecte

He dividit el projecte en dues carpetes per mantenir l'HTML i el CSS separats:

Soste/
├── html/
│   └── OIT.html          # Estructura principal en HTML5
└── css/
    ├── text.css          # Tipografia, colors i enllaços
    ├── taula_llista.css  # Format de les llistes i menú
    └── flexbox.css       # Maquetació i disseny responsive (Flexbox)
